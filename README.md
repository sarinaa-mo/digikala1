# فروشگاه اینترنتی دیجی‌کالا — کلون

پیاده‌سازی صفحه‌ی اصلی دیجی‌کالا با **جاوااسکریپت خالص** (بدون فریم‌ورک)، Vite و Tailwind CSS 4.

> پروژه‌ی آموزشی. تمام حقوق برند و محتوا متعلق به دیجی‌کالا است.

---

## امکانات

- **کاملاً ریسپانسیو** — از ۳۲۰px تا ۱۷۰۰px، بدون اسکرول افقی
- **منوی موبایل** — کشوی کناری با ناوبری سه‌سطحی (منو ← دسته ← زیردسته) + نوار ثابت پایین صفحه
- **مگامنوی دسکتاپ** — دسته‌بندی تودرتو با پیش‌نمایش ستونی
- **سبد خرید** — افزودن، تغییر تعداد، حذف، جمع فاکتور با تخفیف، ماندگار در `localStorage`
- **انتخاب موقعیت مکانی** — نقشه‌ی نشان با مارکر قابل جابه‌جایی و ثبت موقعیت
- **پشتیبانی** — مودال با راه‌های ارتباطی و لینک‌های پرکاربرد
- **۱۰ سکشن محصول** — پرفروش‌ترین‌ها، داغ‌ترین‌ها و ۸ ردیف دسته‌بندی
- **صفحه‌ی لودینگ** با لوگو
- **فوتر کامل** با آکاردئون در موبایل

## کلید نقشه

مودال موقعیت مکانی از SDK نشان استفاده می‌کند و به کلید API نیاز دارد.

۱. از [platform.neshan.org](https://platform.neshan.org) کلید رایگان بگیرید
۲. فایل نمونه را کپی کنید:

```bash
cp .env.example .env
```

۳. کلید را در `.env` قرار دهید:

```
VITE_NESHAN_MAP_KEY=web.xxxxxxxxxxxx
```

بدون کلید، بقیه‌ی مودال (انتخاب شهر، ثبت موقعیت، ذخیره‌سازی) کار می‌کند و به‌جای نقشه یک راهنما نمایش داده می‌شود.

> ⚠️ متغیرهای `VITE_*` در خروجی نهایی **قابل مشاهده** هستند. در پنل نشان حتماً دامنه‌ی مجاز را محدود کنید.

## داده‌ها

`public/db.json` شامل داده‌ی محصولات، بنرها و منوهاست. سکشن‌های محصولی یک‌بار از API عمومی دیجی‌کالا گرفته و داخل همین فایل ذخیره شده‌اند — چون مرورگر به‌خاطر CORS نمی‌تواند مستقیم آن API را صدا بزند.

---

## نکات فنی

**مقداردهی Swiper.** اسلایدها بعد از `fetch` تزریق می‌شوند، پس همه‌ی اسلایدرها با `init="false"` تعریف شده و از `utils/swiper.js` بعد از رسیدن داده mount می‌شوند. بدون این کار Swiper اسلایدها را نمی‌بیند و عرض هرکدام روی ۱۰۰٪ کانتینر می‌ماند.

**کیسینگ مسیرها.** ایمپورت‌ها دقیقاً با نام پوشه‌ها هم‌خوانی دارند. ویندوز حساس به حروف بزرگ و کوچک نیست ولی لینوکس هست — کیسینگ اشتباه باعث شکستن بیلد روی سرور می‌شود.

**کشوها.** پنل‌های کشویی داخل یک شلِ `fixed` با `overflow: hidden` قرار دارند؛ وگرنه در حالت بسته عرض اسکرول صفحه را زیاد می‌کنند.
